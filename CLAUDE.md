# My First Agent Project

A practice project for learning AI assisted development.

## Stack

- Static site: HTML + CSS, no frameworks or build tools yet.

## Commands

- Preview in browser: `open index.html`
- Check git status: `git status`

## Conventions

- Use semantic HTML tags
- Keep all CSS in styles.css — no inline `style=""` attributes or `<style>` blocks
- Write all code, comments and commit messages in English

## Do not

- Do not add JS frameworks or build tools (no React, Vite, npm packages, etc.)
- Do not commit files in /notes
- Do not over-engineer solutions; stick to plain HTML and CSS
