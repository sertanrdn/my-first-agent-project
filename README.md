# Avatar: The Last Airbender – Fan Page

A small static fan page about *Avatar: The Last Airbender*, built with plain HTML and CSS while learning AI-assisted development at [HackYourFuture](https://hackyourfuture.net).

## Features

- **About the show**: a short introduction to the story and its world
- **The Four Nations**: one card per nation, each with its own element color
- **Main characters**: nine character cards with photos
- **Show facts**: key facts at a glance

## Design

The look is inspired by an ancient scroll: warm parchment tones, calligraphic headings (Cinzel) and readable body text (Lora). Muted accent colors stand for the four elements: water, earth, fire and air.

The layout uses a responsive CSS grid, so it works on both phones and desktops. It also includes visible keyboard focus styles and supports the `prefers-reduced-motion` setting.

## Tech stack

- HTML5 (semantic tags)
- CSS3 (custom properties, grid, flexbox)
- No frameworks or build tools

## Run locally

```bash
git clone https://github.com/sertanrdn/my-first-agent-project.git
cd my-first-agent-project
open index.html
```

On Windows or Linux, open `index.html` in your browser by double-clicking it.
